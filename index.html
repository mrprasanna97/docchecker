Check a PDF in seconds

Upload a document and DocCheck looks for the required details and tells you if it was made with design or editing software.

Three steps, one result

  1. Upload your PDFChoose a file or drag it onto the box.
  2. We read the text and file detailsThe file is checked in memory and is not stored.
  3. See what passed and what didn'tEach check is shown with what was found.

What DocCheck looks for

College name

A line that names a college of engineering.

Faculty name

The text after "Name of the faculty:".

Date

A date written like 12/10/2026 or 12-10-26.

DocCheck also reads the file's creator and producer fields. If they show Canva, Picsart, or Photoshop, you get a warning. This gives hints, not proof, so confirm important documents with the issuer.
